# Документация проекта

## Описание базового синтаксиса записи и форматирования

Проект содержит автоматизированные тесты для проверки функциональности:

- Калькулятора с задержкой (slow-calculator)

- Интернет-магазина SauceDemo

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

## Требования (в проекте используются следующие технологии)

- Python 3.8+

- pytest

- selenium

- allure-pytest

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

## Установка

1. Клонировать репозиторий

2. Установить зависимости:

pip install -r requirements.txt

## Запуск тестов

Перед запуском команд нужно тесты должны находиться правильной директории cd lesson_10.

pytest test_calculatop.py

pytest test_shop.py

## Запуск тестов с формированием Allure отчета

1. Убедитесь, что Allure установлен.

2. Запустите тесты с командой:

 -  `pytest test_calculatop.py --alluredir=./allure-results`.

 -  `pytest test_shop.py --alluredir=./allure-results`.

## Запуск просмотра с формиррованного отчета Allure

1. Команда для просмотра сформированного отчёта Allure `allure serve allure-results`

2. Сгенерируйте отчет с помощью команды `allure generate ./allure-results -o ./allure-report`.

3. Откройте отчет с помощью команды `allure open ./allure-report`.

4. В отчете Allure вы увидите:

- Калькулятора с задержкой (slow-calculator)

   - **Название теста**: Тестирование калькулятора: 7 + 8 = 15
   - **Описание теста**: Тест проверяет корректность работы калькулятора.
   - **Шаги теста**:
     - Открытие страницы калькулятора.
     - Установка задержки.
     - Нажатие кнопок.
     - Ожидание результата.
     - Проверка результата.
   - **Результат**: Возвращение текущего результата с экрана калькулятора.

- Интернет-магазина SauceDemo

   - **Название теста**: Например, `Оформление заказа в интернет‑магазине: проверка итоговой суммы`.
   - **Описание теста**: Тест проверяет сценарий оформления заказа: авторизация, добавление товаров в корзину,"
    "переход к оформлению, заполнение формы и проверку итоговой суммы.
   - **Шаги теста**:
     - Открыть главную страницу магазина.
     - Авторизоваться под стандартным пользователем.
     - Добавить товары в корзину.
     - Перейти в корзину и начать оформление заказа.
     - Заполнить данные покупателя
     - Продолжить оформление заказа.
     - Дождаться отображения итоговой суммы
     - Получить и проверить итоговую сумму
   - **Результат**: Отображение итоговой суммы Total: $58.29
